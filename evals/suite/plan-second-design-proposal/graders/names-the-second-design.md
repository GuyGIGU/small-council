The user asked the council to plan a multi-tenant billing change from a complete spec whose open question is one invoices table with a team column or a table per tenant, and asked to see the plan of work and its cost before anything runs.

PASS if the reply stays in council planning; restates the request as behaviour lines the user can check (what a team, a team admin or an existing account sees); says the table choice is hard to undo, so a second designer will make its own design apart from the first (or words to that effect), with the added cost; asks at most one question, with a recommended answer; and asks for the go-ahead before anything runs.

FAIL if it dispatches anyone, proposes a different mode, writes the plan straight away, proposes a panel of experts, treats the table choice as easy to change, or names a second design without its cost.
