# Small Council 2.1.0

A context-engineering council for Claude Code: tailored expert seats review, plan, build, and research in isolated context windows, debate the tough calls, verify adversarially, check finished work against your original request, fit the checks a project is missing, and report every build — shortcuts included — in plain language.

This is the release branch: only the files the plugin runs. It is built from a tagged commit of
main by [its build script](https://github.com/GuyGIGU/small-council/blob/main/scripts/build_release.py) and never edited by hand. The
source, the docs, the tests and the changelog are in the repository: https://github.com/GuyGIGU/small-council

Install, in Claude Code:

```
/plugin marketplace add GuyGIGU/small-council
/plugin install small-council@small-council
```
