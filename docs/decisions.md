# Decisions

The settled decisions of Small Council, one line each, cited by id from code reviews,
[`architecture.md`](architecture.md) and plans. A settled decision is not re-argued and not "fixed" by
a later change. To change one, add a new entry that supersedes it: same table, the old id in its
**Supersedes** cell, and the old row's status set to `superseded by Dn`. Ids are never reused or
renumbered.

**Source** says where the decision was made and argued: an ADR in `docs/design/`, a CHANGELOG
version, or the user's words on a date. **Held by** says what keeps it true: a test, a hook, a helper
refusal, or `prose` when only the text holds it. A `prose` row is a candidate for enforcement.

| D33 | A run file's lock is taken only from a holder that is dead, never from one that reads alive, however old. Its owner file names the holder by the operating system's process id (`os.getpid()`), checked with OpenProcess on Windows (0.04–0.07 ms) and `kill -0` elsewhere; a waiter tries 200 times, 0.1 s apart, then gives up and says who holds the lock. The owner file is made with O_EXCL, an ownerless lock is stale at 10 s, reclaiming goes through `<lock>.recover`, and a lock is stale only while its file still names that holder. An owner line no process could have written (not digits, 0, or past the id type: 2^32-1 on Windows, 2^31-1 elsewhere) is no owner, so the lock goes stale once 10 s old like an ownerless one: no live holder can have written it, and the 10 s covers a writer still taking the lock.
