# A first review with no setup

Read this when council-review starts in a project with no `council.config.md` (doctrine
`01-convene.md`, step 2; D43), before you run `council init scaffold --quick`.

Before sizing, tell the user in a line or two: this project has no council yet, so a quick setup
now and the review straight after — the catalog's seats as it names them, no seat cards or map yet,
kept on this machine. Say its limits once, as facts: no check
was probed, so nothing in this review is checked by machine; Assign picks the catalog's seats by the
change, as always. Then run `council init scaffold --quick` and go on, proposing the size and cost first.
