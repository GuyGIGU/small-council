# A first review with no setup

Read this when council-review starts in a project with no `council.config.md` (D43, D48), before you
run `council init scaffold --quick`.

Tell the owner in a line or two, before the estimate: this project has no council yet, so a quick
setup now makes its folder (kept on this machine) and the review starts straight after. There is
no roster of expert seats to recruit (D72), so nothing in the review waits on the full setup;
`/council-init` does that later — the checks probed, the project's map, and the stack page with its
watch lists — and the review offers it once, at its end. Then run `council init scaffold --quick`
and go on to the estimate.

The quick setup writes none of the book's pages (`references/run/book.md`): its config names their
default places, `council book` says each is not written yet, and the review's brief says so to both
seats. The review's first `council book note` starts known problems; the design page, the stack
page and an adopted decisions log come with `/council-init`.
