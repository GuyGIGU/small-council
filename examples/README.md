# examples/

These are **illustrative outputs of `council-init`** — samples of the `.council/council.config.md`
that the tailoring step writes into a real project after inspecting its stack. They exist to show how
seats get recast and how gates are detected for a given kind of repo; they are not live project
configuration and nothing in `skills/` or `references/` depends on them. Use them as a reference when
you want to see what a tailored council looks like before running `council-init` yourself.
